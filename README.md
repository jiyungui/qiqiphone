# 祁祁phone (小手机前端项目)

一款风格优雅、白灰潮流极简质感的小手机 Web 应用项目。

## 🌟 核心特性

1. **白灰专属色调**：主色调遵循 `#F1F2F1`，边框辅助色 `#D7D7D7`，打造高级杂志与微磨砂亚克力质感。
2. **大容量无损存储 (IndexedDB)**：
   - 摒弃了传统的 `localStorage`（仅5MB且容易爆仓）。
   - 采用浏览器原生 `IndexedDB` 异步数据库引擎，支持保存百兆级别高清无损原图、长文本和自定义配置。
   - 刷新页面、关闭浏览器后所有更换的图片和文字永久保留。
3. **独立模块化架构**：
   - `index.html`：核心骨架与 PWA 支持
   - `css/`：
     - `global.css`：全屏自适应布局、状态栏、三页滑动容器
     - `p1-widget.css`：P1 顶部杂志排版小组件
     - `p2-widget.css`：P2 左侧黑胶唱片闪粉亚克力播放器
     - `apps.css`：第一页右侧 6 个应用图标
     - `dock.css`：底部悬浮毛玻璃 Dock 栏
     - `modal.css`：无损图文实时编辑弹窗
   - `js/`：
     - `storage.js`：IndexedDB 存储引擎封装
     - `p1-widget.js`：P1 动态渲染与持久化交互
     - `p2-widget.js`：P2 唱片旋转、播放控制与编辑
     - `apps.js`：右侧 6 个应用管理
     - `dock.js`：底部 4 个应用管理
     - `pagination.js`：3 页平滑手势滑动与圆点指示
     - `edit-modal.js`：可视化表单与无损图片上传器
     - `app.js`：主入口与移动端视口适配
4. **移动端全屏沉浸自适应 (Safari / Chrome / Android)**：
   - 支持 `viewport-fit=cover` 与安全区 `safe-area-inset`。
   - 支持 PWA `standalone` 模式（在 iOS Safari 点击“添加到主屏幕”或安卓浏览器“保存到桌面”即可享受如同原生 App 的全屏体验）。
   - 在桌面端以精致的手机画框呈现，在移动端自动展开为全屏栅格流式分配。

## 📱 第一页内容结构

- **顶部小组件 (P1)**：潮流杂志排版（MEETING YOU、Archer 头像、DAILY 标牌、誓言文案、天气指标、情话卡片、日记便签）。
- **下方左侧小组件 (P2)**：黑胶唱片闪粉播放器（支持唱片旋转、播放控制、歌名、进度条）。
- **下方右侧 6 个 APP**：`chat` - `记忆世界` - `相册` - `日记` - `世界书` - `老福特`。
- **底部 Dock 栏**：`设置` - `美化` - `短信` - `频道`。

## 💡 自定义操作方式

- **点击 P1 / P2 小组件**：唤起编辑面板，可直接上传本地高清图片和修改任意文字。
- **长按（移动端）或右键（桌面端）任意 APP 图标**：自定义该应用的名称与图标图片。
- **点击保存**：即刻通过 IndexedDB 无损写入本地数据库，刷新不丢失。
